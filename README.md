# 🚗 Dashboard de Vehículos Interactivo | Data Analytics App 📊

> **"Transformando datos crudos en decisiones estratégicas a través de visualizaciones interactivas."**

¡Bienvenido/a a mi portafolio de datos! 👋 Este proyecto es una **aplicación web interactiva** construida para explorar, analizar y visualizar un conjunto de datos sobre vehículos en venta. A través de una interfaz limpia y dinámica, los usuarios pueden interactuar con los datos en tiempo real, descubriendo tendencias de precios, distribución por kilometraje y características técnicas del mercado automotriz.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido desarrollado utilizando las herramientas más modernas del ecosistema de datos:

*   **[Python](https://www.python.org/)**: El motor principal detrás de la lógica y manipulación de la información.
*   **[Streamlit](https://streamlit.io/)**: El asombroso framework que da vida a la aplicación web, permitiendo crear interfaces de usuario rápidas y estéticas en tiempo récord.
*   **[Plotly Express](https://plotly.com/python/plotly-express/)**: La biblioteca estrella para renderizar gráficos **altamente interactivos** y de calidad profesional.
*   **[Pandas](https://pandas.pydata.org/)**: Nuestro gran aliado para la limpieza, manipulación y estructuración del *dataset*.

## 🚀 Instalación y Ejecución Local

¿Quieres probar la aplicación en tu propia máquina y ver el código en acción? ¡Es muy sencillo! Sigue estos pasos para levantar el entorno local:

1. **Clona este repositorio**
   Abre tu terminal y ejecuta el siguiente comando para descargar el proyecto en tu computadora:
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   cd tu-repositorio
   ```

2. **Instala las dependencias necesarias**
   Es altamente recomendable usar un entorno virtual. Una vez dentro de tu entorno, instala los paquetes listados en el archivo de requerimientos:
   ```bash
   pip install -r requirements.txt
   ```

3. **Inicia la magia con Streamlit**
   Lanza el servidor local para ver la aplicación web interactiva:
   ```bash
   streamlit run app.py
   ```
   *¡Listo!* 🪄 Tu navegador web predeterminado se abrirá automáticamente (usualmente en `http://localhost:8501`) mostrando tu espectacular panel de control.
